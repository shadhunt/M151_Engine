# background/

An alternate map (`land/test-land.png`) copied over from the main
project. **Not used by the demo** -- `PlayScene` loads
`assets/images/map/m151_practice_stage.png` instead (see `engine/config.py`
-> `MAP_IMAGE`).

Swap it in yourself as a first exercise: change `MAP_IMAGE` in
`engine/config.py` to point here instead, then adjust
`data/enemies.json` spawn offsets if the new map is a different size.
